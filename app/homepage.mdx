# Welcome to Blog app 

This is a **modern blogging platform** built with Next.js, featuring user authentication, blog post management, and a clean, intuitive interface.

## Features
- **Create and manage Blogs** - Write and publish your thoughts
- **User profiles** - Personalize your experience
- **Authentication** - Secure login and registration
- **Comments** - Engage with other users through comments on blog posts

## Getting Started
To start exploring:
1. [Register](/register) for a new account
2. [Login](/login) to access your dashboard
3. [Create a new blog post](/blogs/new) and share your ideas with the world
4. View [all blog posts](/blogs) and engage with the community

---

Built using Next.js, React, and Drizzle ORM.

Source code available on [GitHub](https://github.com/Franco-Redivo/blog-app-next).
